About this project

A certification site built like an engineering resource.

The goal is not to mirror an old FAQ page. It is to maintain a useful, transparent and current reference that helps people learn, prepare and apply Claude skills.

Editorial principles

Official first

Time-sensitive exam facts should point back to current Anthropic sources.

Date important facts

Program details change. Verification dates and changelogs reduce silent staleness.

No exam dumps

Practice material is original and concept-focused.

Useful beyond certification

Concept guides connect exam topics with real production decisions.

Content labels

✓ OFFICIAL / VERIFIED means the claim is grounded in a current official source. 💡 EXPERIENCE means practical preparation guidance. 👥 COMMUNITY means useful but unofficial observations.

Contributing

This project is designed for GitHub. Future updates can be proposed through pull requests or issues. Contributions should include a source for factual certification changes and must not contain confidential or reconstructed exam questions.
