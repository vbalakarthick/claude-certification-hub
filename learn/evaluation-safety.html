Evaluation & Safety

Define what good and safe look like before production traffic defines them for you.

← Concept library

Evaluation stack

  • Representative test cases and edge cases.
  • Deterministic checks where possible.
  • Human or model-based grading where judgment is required.
  • Regression gates before prompt/model changes.
  • Production monitoring for quality, latency, cost and failures.

Safety stack

Use layered controls: input validation, least-privilege tools, sensitive-data handling, output checks, human review, audit logs and fail-closed behavior for critical actions.

Prompt injection

Treat external content as untrusted data, not policy. Tool permissions must be independently enforced.
