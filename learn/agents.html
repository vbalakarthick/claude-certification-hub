Agent loop

Goal → reason/plan → choose action → call tool → observe → update state → continue or stop.

When to use agents

Use agentic patterns when the next action depends on intermediate observations. Prefer deterministic workflows when the process is known in advance.

Production controls

  • Step, token, time and cost budgets.
  • Human approval for high-impact actions.
  • Idempotent and retry-safe tools.
  • Checkpointing for long tasks.
  • Tracing and safe stop conditions.
