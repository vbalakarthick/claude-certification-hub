Context Engineering

Treat context as a finite, valuable system resource.

← Concept library

Key patterns

  • Keep only task-relevant instructions and evidence in active context.
  • Use retrieval for large or changing knowledge.
  • Use caching for stable repeated prefixes when reuse is high.
  • Separate durable memory, session state and ephemeral tool results.
  • Design compaction or checkpointing for long-running work.

Reliability lens

Context problems can look like reasoning problems. Before changing the model, verify that the right information is present, current and unambiguous.
