Tool design

  • Use clear names, descriptions and narrow typed schemas.
  • Return structured errors that support recovery.
  • Separate read-only from state-changing operations.
  • Enforce authorization in the tool/service layer, not only in prompts.
  • Require approval for high-impact irreversible actions when appropriate.

MCP mental model

Model Context Protocol standardizes how AI applications connect to tools, resources and prompts. Security still depends on authentication, authorization, least privilege and careful treatment of untrusted content.
