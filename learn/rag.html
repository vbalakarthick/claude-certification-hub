Concept library

Retrieval-Augmented Generation

Use retrieval when knowledge is too large, dynamic or auditable to keep directly in prompts.

← Concept library

Pipeline

Ingest → normalize → chunk → index → retrieve → optionally rerank → assemble context → generate → cite/evaluate.

Common failure modes

  • Retrieval misses the right evidence.
  • Chunks lose needed context.
  • Too many irrelevant chunks drown out the answer.
  • The model overclaims beyond retrieved evidence.
  • Evaluation measures style but not retrieval quality.

Architecture lens

Compare RAG with long context based on freshness, scale, latency, cost, traceability and reuse.
