Prompt Engineering

Design prompts that are explicit, structured and testable.

← Concept library

Core principles

  • State the task, audience, constraints and expected output clearly.
  • Add relevant context that helps Claude make better judgments.
  • Use diverse examples for formatting and edge cases.
  • Use structured tags when instructions, data and examples are mixed.
  • Evaluate prompts on representative test cases rather than one example.

Reusable structure

<role>You are ...</role>
<goal>What success looks like</goal>
<context>Relevant facts</context>
<instructions>Steps and constraints</instructions>
<examples>Representative examples</examples>
<output_format>Exact expected shape</output_format>
